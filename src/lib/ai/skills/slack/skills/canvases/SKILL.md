---
name: canvases
description: Create shareable Slack canvas documents from markdown.
criteria: Use when the user wants a report, summary, or write-up as a persistent document rather than a chat message.
tools: [slack_create_canvas]
minRole: member
mode: inline
---

- A canvas is a formal document — write the title and body in normal professional casing even if your chat tone is lowercase.
- Markdown supports headings, lists, tables, code blocks, and links.
- Creating a canvas requires approval. Optionally share it to a channel; always give the user the canvas link.
